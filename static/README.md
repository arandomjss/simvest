# Simvest Demo only frontend with login js Project

This folder contains the demo version of the Simvest project, which is built using HTML, CSS, and JavaScript. It serves as a static frontend prototype for the application.

## Structure
- `index.html`: The main HTML file for the demo.
- `styles.css`: The CSS file for styling the demo.
- `assets/`: Contains images and other static resources.

## Purpose
This demo is a static representation of the Simvest application. The real project will be developed using React for the frontend, Python Django for the backend, and a database for data storage.
