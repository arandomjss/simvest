# Simvest - Paper Trading Dashboard

Simvest is a modern and interactive paper trading dashboard designed to simulate stock market trading. It provides users with a platform to practice trading strategies, monitor portfolio performance, and analyze market trends without any financial risk.

## Features (just started)

- **Dashboard**: Overview of portfolio value and performance.
- **Markets**: Explore market trends and stock prices.
- **Portfolio**: Track your holdings and their performance.
- **Orders**: Place buy/sell orders with ease.
- **Reports**: Generate detailed trading reports.
- **Leaderboard**: Compete with other users in simulated trading.
- **Pro Mode**: Unlock advanced charts and real-time data.

## How to Use

1. Clone the repository to your local machine.
2. Open `index.html` in your browser to view the application.
